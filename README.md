# SpaceFacts

**Explore the planets of our Solar System!**

SpaceFacts is a website dedicated to sharing facts about the eight planets in our Solar System. Explore the planets, learn interesting facts, and compare their features.

## What's on SpaceFacts?

- **All eight planets** — Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune.
- **Planet facts** — Discover information about each planet.
- **Quick comparisons** — Compare the planets and their properties.
- **Space resources** — Find links to further information about space exploration.

## How to Use

1. Open the homepage.
2. Choose a planet to explore.
3. Read its facts and discover more about our Solar System.

## Built With

- HTML
- CSS
- Python and Flask for local development

## Running Locally

If you want to run SpaceFacts using Flask:

1. Install Python.
2. Install Flask:

   ```bash
   py -m pip install flask
   ```

3. Run the application:

   ```bash
   py app.py
   ```

4. Open http://127.0.0.1:5000/ in your browser.

## Publishing

SpaceFacts can be hosted as a static website using GitHub Pages.
